# Café Lærke

Demo website for a fictional bakery and café in Aarhus C, edited through Britesite on camera for the Britesite product video. Not a real business; the site is `noindex`.

**Stack:** Next.js 16 (App Router, statically prerendered) · React 19 · TypeScript · Tailwind CSS v4.

```bash
npm install
npm run dev
npm run build
npm run lint
```

See `SITE_GUIDE.md` for where things live.
